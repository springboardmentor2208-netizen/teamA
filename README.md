# Clean Street – Civic Issue Reporting App

This is a full-stack web application developed as part of the Infosys Internship Program.

The app allows users to report civic issues such as garbage, potholes, water leakage, etc.,
and track their status in real time.

---

## Team Workflow

- Main Branch: Final submission
- Dev Branch: Daily progress
- Individual branches for each team member

No one directly pushes to the main branch.

---

## Tech Stack

Frontend: React  
Backend: Node.js, Express  
Database: MongoDB

---

## Daily Demo

All daily work is merged into the dev branch and shown to the mentor.
