# Backend

This folder contains all backend-related code for the TeamA project.

## Tech Stack
- Node.js
- Express.js
- MongoDB
- JWT Authentication

## Responsibilities (Milestone 1)
- User registration and login APIs
- Role-based authentication
- User profile APIs
- User complaint list APIs

## Rules
- Only backend team members should work in this folder
- Do NOT modify frontend folder
- Always work on your own branch
- Raise Pull Requests to the `develop` branch only
