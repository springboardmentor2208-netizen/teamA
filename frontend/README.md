# 🎨 Frontend — Clean Street Civic App

## 📌 Overview

This is the **frontend** of the *Clean Street Civic Issue Reporting Application*.
It is built using **React (Vite)** and provides an interactive UI for users and admins.

---

## ✨ Features

* 🔐 User Login & Registration UI
* 📊 User & Admin Dashboards
* 📝 Issue Reporting Interface
* 📱 Responsive Design
* 🔗 Seamless API Integration

---

## 🧱 Tech Stack

* ⚛️ React.js (Vite)
* 🎨 CSS
* 🔗 Axios (API calls)

---

## 📂 Folder Structure

```bash
components/   → Reusable UI components  
pages/        → Application screens  
assets/       → Images & static files  
services/     → API integration  
```

---

## ⚙️ Getting Started

### 1️⃣ Install Dependencies

```bash
npm install
```

### 2️⃣ Run Development Server

```bash
npm run dev
```

---

## 🌐 API Configuration

Make sure backend is running at:

```bash
http://localhost:5000
```

## 🎯 Purpose

To provide a **clean, responsive and user-friendly interface** for reporting and managing civic issues.
