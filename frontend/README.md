# Frontend

This folder contains all frontend-related code for the TeamA project.

## Tech Stack
- React
- Vite
- HTML / CSS
- JavaScript

## Responsibilities
- Login page
- Registration page
- User dashboard UI
- Profile edit UI

## Rules
- Only frontend team members should work in this folder
- Do NOT modify backend folder
- Always work on your own branch
- Raise Pull Requests to the `develop` branch only
